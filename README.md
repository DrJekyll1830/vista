# ویستا — کتاب و ارائه

مخزن کاری پروژهٔ ویستا: سوپر اپلیکیشن هوش‌مصنوعی‌محور مبتنی بر قرارداد امضاشده.

## ساختار

```
presentation/index.html    ارائهٔ تعاملی (فارسی، دسکتاپ، خودبسنده)
book/                      کتاب؛ هر فصل یک فایل .md
build/build.sh             ساخت PDF از پوشهٔ کتاب
analysis/                  یادداشت‌های تحلیلی دورهای طراحی (انگلیسی)
```

## ارائه

فایل `presentation/index.html` خودبسنده است — بدون وابستگی به هیچ سرور یا بستهٔ خارجی
جز فونت گوگل. کافی است در مرورگر باز شود.

پیمایش: کلیدهای جهت‌دار یا `Space` · نمای کلی با `O` · تغییر تم با دکمهٔ گوشه.

## ساخت کتاب

```bash
./build/build.sh          # ساخت PDF
```

نیازمندی‌ها: `pandoc`, `xelatex` (پکیج `texlive-xetex`), و فونت `Vazirmatn`.

## قواعد نگارش

- هر پاراگراف با یک واژهٔ فارسی آغاز می‌شود. اگر ناچار به شروع با واژهٔ لاتین بودیم،
  پیش از آن «به واقع» می‌آید.
- ارقام فارسی در متن، ارقام لاتین در بلوک کد و شناسه‌های فنی.
- اصطلاحات فنی: تنها آن‌هایی به لاتین می‌مانند که معادل پایدار فارسی ندارند
  (MCP، API، SSO، HSM، EVM). بقیه ترجمه و یکدست به‌کار می‌روند.
- واژه‌نامه در `book/90-ضمائم/90-01-واژه‌نامه.md`.
