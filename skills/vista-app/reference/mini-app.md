# مینی‌اپ — چهرهٔ گرافیکی اپ

مینی‌اپ صفحهٔ وبِ خودِ اپ است که داخل ویستا، در یک iframe، باز می‌شود؛ برای کاربری که ترجیح می‌دهد ببیند و کلیک کند. اگر از قبل وب واکنش‌گرا دارید، نیمی از کار انجام شده است: یک مسیر تازه که توکن ویستا را می‌فهمد، همان صفحه را با هویت کاربر نشان می‌دهد.

## چگونه باز می‌شود

ویستا آدرس `mini_app_url` مانیفست را می‌گیرد و به آن `?token=` می‌چسباند:

```
https://app.example.ir/vista/mini?token=<base64url(json)>.<signature>
```

توکن دو بخش دارد که با نقطه جدا شده‌اند:

1. `base64url` از این JSON:
   ```json
   { "user_id": "usr_v2kqzs0nybxn61np", "user_ref": "u_zs0nybxn61", "exp": 1788173400000 }
   ```
   - `user_id`: شناسهٔ خام کاربر (**بدون** پیشوند `user:`؛ برخلاف `_meta.vista.user_id` که با پیشوند می‌آید).
   - `user_ref`: همان شبه‌نامی که در ابزارهای MCP می‌گیرید (`u_` + ده نویسهٔ آخر شناسه) — کلید مناسب برای نگهداری دادهٔ کاربر در سمت اپ.
   - `exp`: انقضا به میلی‌ثانیهٔ یونیکس؛ ۱۵ دقیقه پس از صدور.
2. امضای Ed25519 سکو **روی همان رشتهٔ base64url** (نه روی JSON خام)، به‌صورت base64.

توکن هر بار که کاربر صفحهٔ اپ را در ویستا باز می‌کند تازه صادر می‌شود (`GET /api/apps/:id` → `mini_token`).

## راستی‌آزمایی

کلید عمومی سکو از `GET <VISTA_URL>/api/platform` می‌آید (`public_key`، base64 از ۳۲ بایت خام). آن را یک بار بخوانید و نگه دارید.

```js
import { verifyMiniAppToken } from './lib/vista-sign.mjs';
const payload = verifyMiniAppToken(PLATFORM_PUBLIC_KEY, url.searchParams.get('token'));
// payload = { user_id, user_ref, exp } یا null (امضای نامعتبر، ساختار خراب، یا منقضی)
```

بدون کتابخانه، همان سه گام: جدا کردن با `.`، راستی‌آزمایی امضا روی رشتهٔ اول با کلید سکو، سپس `JSON.parse(base64url-decode)` و بررسی `exp > Date.now()`.

توکن نامعتبر یعنی **مهمان**: صفحه را نشان دهید، اما هیچ دادهٔ شخصی‌ای نه. خطا ندهید؛ اپ مرجع همین کار را می‌کند.

## چه می‌تواند و چه نمی‌تواند

مینی‌اپ **می‌تواند**:

- وضعیت و سابقهٔ کاربر را (با `user_ref`) از بک‌اند خودتان بخواند و نشان دهد
- فهرست‌ها، جزئیات، مقایسه، جست‌وجو — هر چیزی که وضعیتی را عوض نمی‌کند
- به بک‌اند خودتان درخواست بزند (با همان توکن، تا وقتی منقضی نشده)
- کاربر را راهنمایی کند که «برای خرید، از دستیار بخواهید قرارداد بیاورد»

مینی‌اپ **نمی‌تواند**:

- امضا بگیرد یا چیزی را «تأیید» کند که اثر مالی یا تعهدی دارد. امضا فقط در نمای قرارداد ویستا و با پلهٔ امضای سکو انجام می‌شود؛ هیچ دکمه‌ای در صفحهٔ شما جای آن را نمی‌گیرد.
- درگاه پرداخت یا شمارهٔ کارت بخواهد. پول در ویستا فقط با اثر `wallet.pay` در قرارداد امضاشده جابه‌جا می‌شود.
- در این نسخه، قراردادی را «به گفت‌وگو بفرستد». راه ساختن قرارداد، ابزار `build_*` است که دستیار یا صفحهٔ اپ در ویستا صدا می‌زند. اگر کاربر از مینی‌اپ چیزی را انتخاب کرد، آن را در بک‌اند خودتان کنار `user_ref` نگه دارید تا ابزار ساختن بعدی (وقتی کاربر از دستیار بخواهد) از آن استفاده کند.
- نام کاربری/رمز ویستا یا کد یک‌بارمصرف بخواهد. هیچ چیزی از این دست وجود ندارد که اپ به آن نیاز داشته باشد.

قاعدهٔ کلی همان قاعدهٔ کتاب است: **خواندن آزاد است؛ نوشتن قرارداد است**. مینی‌اپ چهرهٔ «خواندن» شماست.

## سبک

- `<html lang="fa" dir="rtl">` و `<meta name="viewport" content="width=device-width,initial-scale=1">`
- قلم: `font-family: Vazirmatn, system-ui, sans-serif` (اگر Vazirmatn را خودتان سرو می‌کنید، `font-display: swap`)
- واکنش‌گرا و بدون عرض ثابت؛ صفحه در موبایل، در یک ستون، داخل iframe باز می‌شود
- رنگ برند خودتان مجاز است (همان `appearance.color` مانیفست بهتر است)؛ چیدمان ساده و سبک
- ارقام فارسی در متن (`toLocaleString('fa-IR')`)، مبلغ به تومان
- بدون پاپ‌آپ، بدون درخواست اعلان مرورگر، بدون ردیاب شخص ثالث
- هدرهای HTTP: `X-Frame-Options` نگذارید (یا `SAMEORIGIN` نگذارید)؛ به جای آن `Content-Security-Policy: frame-ancestors <آدرس ویستا>` تا فقط ویستا بتواند صفحه را قاب کند

## نمونهٔ کمینه

```js
// در lib/example-server.mjs → مسیر /mini
const payload = verifyMiniAppToken(PLATFORM_KEY, url.searchParams.get('token') ?? '');
const who = payload ? `کاربر ${payload.user_ref}` : 'مهمان (توکن نامعتبر یا منقضی)';
res.end(`<!doctype html><html lang="fa" dir="rtl"><head><meta charset="utf-8">
<meta name="viewport" content="width=device-width,initial-scale=1"><title>${APP_NAME}</title>
<style>body{font-family:Vazirmatn,system-ui,sans-serif;margin:0;padding:16px}</style></head>
<body><h1>${APP_NAME}</h1><small>${who}</small>
<p>برای خرید، از دستیار ویستا بخواهید قرارداد بیاورد؛ این صفحه فقط نشان می‌دهد.</p></body></html>`);
```

## چک‌لیست مینی‌اپ

- [ ] `mini_app_url` در مانیفست، با HTTPS در تولید
- [ ] توکن با کلید سکو راستی‌آزمایی می‌شود و انقضا بررسی می‌شود
- [ ] توکن نامعتبر → حالت مهمان، نه خطا
- [ ] هیچ دکمهٔ «پرداخت/تأیید/امضا» با اثر واقعی در صفحه نیست
- [ ] RTL، Vazirmatn، واکنش‌گرا، قابل قاب‌شدن توسط ویستا
